# 地端版（單一 HTML 檔 + 資料包）

跟 MGPA 工具組同樣的用法：**不需要 Google 帳號、伺服器、網路或安裝任何東西**。
把 `dist/FS-local.html` 複製到電腦任何位置，用 Chrome / Edge **雙擊**就能用。
所有資料只存在你這台電腦的瀏覽器裡，不會上傳到任何地方。

後端是 `src/*.gs`（計算引擎與資料存取），前端是 `src/index.html` / `script.html` / `style.html`，
build 時原封不動放進這一個檔案。`tools/verify-local.js` 會用 Gate F 實際數字逐格確認算出來的結果正確。

## 日常使用

頁首下方多了一條地端版工具列：

| 按鈕 | 用途 |
|---|---|
| 使用者：XXX | 點一下填自己的名字，會記在稽核紀錄與匯出的資料包上（地端版沒有 Google 帳號可用） |
| 匯出全部 | 整份資料庫存成一個資料包（`FS資料包_全部_日期.json`），**這是備份** |
| 匯出目前車型 | 只匯出上方選的車型，交給同事合併 |
| 匯入資料包… | 選檔後可選「合併匯入」或「取代整個資料庫」 |
| 更多… | 載入示範資料、清空所有資料 |

**修改會自動暫存在瀏覽器裡**，關掉再打開資料還在。但瀏覽器暫存不是正式保存：
清除瀏覽資料、換電腦、換瀏覽器就會不見。所以工具列會顯示「N 次修改尚未匯出」，
**請養成定期「匯出全部」的習慣**，把資料包存到共用資料夾或自己的備份位置。

## 多人協作：每人負責自己的車型

1. 每個人在自己電腦上維護自己負責的車型。
2. 要給別人看時，選好車型 →「匯出目前車型」→ 把檔案放到共用資料夾。
3. 其他人「匯入資料包…」→「合併匯入」，就能在儀表板上跟自己的車型並排比較。
4. 對方之後改了數字，再給一包新的、再合併一次即可（同一個車型以新資料包為準，不會重複）。

合併的規則：

- **資料包裡有的車型，以資料包為準整個取代**（車系、情境、所有輸入資料）；資料包裡沒有的車型完全不動。
  誰負責的車型，誰的資料包說了算。合併前會列出哪些車型會被取代、哪些是新增，確認後才寫入。
- **自訂科目自動處理撞號**：科目表是全域共用的，兩個人各自新增的科目可能拿到同一個代碼（例如都是 b15）。
  合併時逐一比對：名稱與父科目都相同就視為同一個科目；代碼撞到別的科目就自動改號，金額與攤提落點跟著改過去。
- 車系代號在本機屬於別的車型時會擋下來，請先在其中一邊改名。
- 沒有掛在情境底下的全域參數，本機已經有的不會被覆蓋。

## 取代整個資料庫

適合還原備份或換電腦：目前瀏覽器裡的所有資料都換成資料包的內容（包含資料包裡沒有的車型會被清掉）。
建議先「匯出全部」再取代。

## 注意事項

- 同一個檔案不要同時開兩個分頁編輯。一邊存檔後，另一邊會停止寫入並提示重新整理，避免互相覆蓋。
- Chrome / Edge 對所有用雙擊打開的本機 HTML 共用同一份暫存，所以同一台電腦上的兩份 `FS-local.html`
  副本會看到同一份資料。要分開管理請用匯出/匯入。
- 無痕視窗或公司政策封鎖暫存時，工具列會出現紅色警告：資料只在這一頁的記憶體裡，關閉前務必匯出。
- 資料包是 JSON 純文字，沒有公式、沒有計算結果（PLResult 隨時可以重算）。欄位名稱跟 `docs/data-schema.md` 的分頁欄位相同。

## 開發者

```
local/
├─ gas-shim.js   # 瀏覽器版的 Apps Script 模擬層(記憶體試算表、LockService、Session...)
├─ pack.js       # 資料包格式：匯出、讀取檢查、只取部分車型、合併(含科目改號)
├─ host.js       # 後端主機：.gs 後端 + 暫存 + google.script.run 替身
├─ boot.js       # 開機：在前端 script.html 執行前架好主機
├─ local-ui.js   # 地端版工具列與匯入對話框
└─ local-ui.css
tools/build-local.js   # 組成 dist/FS-local.html(單一檔案)
tools/verify-local.js  # Node 驗證：數字與驗算層相同、暫存、資料包、合併
tools/e2e-local.js     # 瀏覽器端對端測試(需要 Playwright，找不到時略過)
```

改了 `src/` 或 `local/` 之後：

```bash
node tools/build-local.js     # 重新產生 dist/FS-local.html
node tools/verify-local.js    # 會檢查 dist 是不是最新的
node tools/e2e-local.js       # 有 Playwright 時跑瀏覽器測試
```

`.gs` 被整段包進 `FSBackendFactory(G)` 函式裡，跟前端 `script.html` 的全域名稱互不干擾；
`G` 是模擬的 Apps Script 全域物件。每次前端呼叫都比照 Apps Script「每次都是新的執行」清掉單次執行快取，
參數與回傳值都走一次 JSON，跟 `google.script.run` 的序列化行為一致。
