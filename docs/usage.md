# 車型損益試算系統 v2 — 使用說明

個人/小組使用版本（無登入權限控管、無情境鎖定）。完全離線：圖表自己產生 SVG，不載入任何外部資源。
打開方式、資料包的匯出/匯入/合併見 `../local/README.md`；資料結構見 `data-schema.md`，架構見 `architecture.md`。

## v2 改了什麼

| 以前的痛點 | v2 的做法 |
|---|---|
| 介面老舊、找不到東西 | 左側導覽依工作流程分四組（結果呈現 → 輸入資料 → 計算設定 → 主檔，共 10 頁），右上角固定顯示目前的車型/情境；有未儲存的修改時底部浮出「儲存 / 放棄」(Ctrl+S 也可以)，切頁前會先確認；成功/錯誤訊息改成右上角提示；確認與輸入改用對話框 |
| 科目設定很難操作；計算來源、公式寫死 | 新的「科目與公式」頁：左邊科目樹、右邊編輯器。每個科目選一種**計算來源**（手動輸入 / 公式 / 開發總投攤提），公式可以自由寫，邊打邊檢查、邊看各車系試算結果 |
| 科目在不同車型間差很多，拿一個車型當基底誤差很大 | **每個車型各自一份科目表**。新車型可以選從標準範本或從某個既有車型複製；同一個車型裡個別車系算法不同時，還可以設「車系個別公式」；開發總投可以只攤給部分車系 |
| 簡報上的「現況與目標差距、作法」要另外整理 | 新的「GATE 報告」頁：差距摘要、差距拆解瀑布圖、現況 vs 目標對照(含對應作法與說明)、目標成本作法清單、細車型 FS、前回 vs 本回、開發總投 by 部門，一頁一張投影片，可列印/存 PDF、複製表格貼進 PowerPoint |
| 調整順序要一格一格按 ▲▼ | 全系統改成拖曳 ⠿ 把手（放開就生效），鍵盤也可以：把手取得焦點後 Alt+↑/↓ |

**v2.1 再加上**：科目與公式頁重新設計（像損益表的科目樹 + 一步一步的編輯器、公式用科目名稱寫、輸入 `[` 自動完成、常用寫法範本）、
從 Excel 貼上、目標反推與敏感度分析、GATE 報告的作法對帳與損益兩平月銷量。

**v2.2**：公式編輯器改成「一行一項」（每行選科目 × 比率，旁邊直接顯示這一行多少）＋「自由公式」（膠囊，IF/ROUND 等複雜公式用），
拿掉常用寫法按鈕；刪掉營業淨利(K)另建淨利科目時，儀表板、GATE 報告、目標反推會改看新的淨利科目。

**v2.3（精簡重複的功能）**：
- 瀑布圖統一在「瀑布圖工具」：儀表板拿掉「差異比較」子頁與「損益瀑布」圖，改成子頁籤列右邊的「瀑布圖…」
  （選兩欄 = 差在哪些科目，選同一欄 = 從收入扣到營業淨利）；差異數字看損益表「第二小欄 → 與基準的差異」。
  GATE 報告的差距拆解、目標反推的結果都可以「在瀑布圖工具開啟」。
- 目標反推的「單項」「多項（組合拳）」合成一張卡片：只選一項就是單項反推，按「＋ 加一個項目」就變組合拳。
- 「車型主檔 / 車系設定 / 情境設定」合成一頁「車型與情境」；「匯率設定」併進「參數與匯率」頁下半部。
  同一頁有好幾個表格時，底部的「儲存」/Ctrl+S 會把每個改過的表格都存起來。
- 「從其他情境帶入」只留在「車型與情境 → 情境」（可勾選要帶哪些資料）；開發總投頁上那個會覆蓋全部資料的「帶入」拿掉。
- 車系順序只在「車型與情境 → 車系」拖曳（成本與費用頁上方的車系順序條拿掉）。
- 金額單位全系統共用（元 / 千元 / 萬元）：在儀表板、GATE 報告或瀑布圖工具任何一頁改，其他頁跟著變。
- 儀表板不常改的選項（重點指標卡片、售價結構、標示最佳/最差、全部收合）收進「⚙ 顯示設定」。

## 開始使用

用 Chrome / Edge 雙擊 `dist/FS-local.html`。第一次打開是空的資料庫，可以：

- 「匯入資料包…」載入同事給的或自己備份的資料包（v1 的資料包也能讀，會自動升級）；
- 「更多…」→「載入示範資料」先看看（DA Gate F 現況與目標，含說明與作法；另一個車型 DE 的科目表跟 DA 不同）；
- 或直接從「車型與情境」開始建立。

## 建立車型與情境（主檔）

「車型與情境」一頁由上而下是車型、車系（目前車型）、情境（目前車型）、情境快照四個區塊。

1. **車型** →「＋ 新增車型」：填代號，並選擇科目表從哪裡開始 —— 標準範本，或複製一個科目結構比較接近的既有車型。
   代號之後可以用「改代號」修改，所有引用它的資料（車系、情境、科目表、作法…）會一起改。
2. **車系**：新增車系（3人貨車 / 9人客貨車…）。拖曳 ⠿ 調整順序，放開就存，所有頁面的車系欄位照這個順序。
3. **情境**：按「＋ 新增情境…」，在對話框選 GATE 別、情境性質（現況/目標）、情境名稱（預設 性質＋今天日期，改性質會跟著換）。
   可以選來源情境整批帶入（銷售構成、銷貨成本、開發總投、營業費用、費率、報告說明、改善作法可以勾選），只能在同一個車型內帶入；
   已經建好的情境用「帶入目前情境…」，同一組勾選。
   拖曳 ⠿ 調整情境選單的順序。

## 每個情境要填的數字（輸入資料）

右上角選好車型與情境之後：

4. **銷售構成與售價**：每個車系一列。改台數 → 構成比重算；改構成比 → 依車型月總台數反推台數，兩者永遠一致。
   這裡的售價欄位是售價結構(P1~P9)公式的來源（公式裡的 `[建議零售價]`、`[廢車處理費(含稅)]`…）。
5. **成本與費用 → 銷貨成本**（頁面上方切換 銷貨成本 / 營業費用）：列 = 成本項目、欄 = 車系，填單台金額，可選幣別（依「參數與匯率」頁的匯率換算）。
   只有計算來源是「手動輸入」的科目會出現在上半部；公式或開發總投攤提的科目列在下方唯讀，滑鼠移到金額上可以看完整計算過程。
   「報告說明」欄會直接印在 GATE 報告的「說明」欄（在報告上改也是同一份）。車系欄位的順序在「車型與情境 → 車系」拖曳。
   - **從 Excel 貼上**：在 Excel 選一塊數字複製，點表格裡的起始格按 Ctrl+V，會往右、往下依序填進去
     （千分位逗號、`(1,234)` 負數、`-` 當 0 都認得；銷售構成、開發總投等所有表格都能這樣貼）。
   - **從 Excel 貼上整張表…**：連科目名稱與車系標題一起複製貼上，依名稱自動對應（順序不用一樣），
     先顯示對應結果讓你確認；找不到的科目可以自動新增，公式/攤提科目會略過。
   這頁新增/刪除的項目只影響目前的車型。
6. **開發總投**：每一列 部門 → 大類（設備/模具/費用）→ 攤提落點 → 金額。
   - **分攤車系**：預設全車系分攤（÷ LC 總台數）；勾選部分車系 = 只攤給這些車系（÷ 這些車系的攤提台數），
     對應簡報上「中低規式樣及 TNCAP 由各車型分別攤提」的情況。
   - 目標情境才有挑戰低減目標%，可以直接改低減後金額反推%。
   - 下方表格即時試算每個攤提落點的總額、加權單台攤提，以及每個車系各自的單台攤提。拖曳 ⠿ 調整列順序。
7. **成本與費用 → 營業費用**：同銷貨成本，科目分銷售費用 / 產品貢獻前費用 / 固定營業費用 / 前瞻費用。

## 計算設定（目前車型）

8. **科目與公式**（這個車型自己的科目表）
   - **左邊長得像損益表**：科目縮排在它的小計底下，旁邊直接顯示目前情境的金額（加權平均），群組可以收合
     （售價結構預設收起來）。圖示：✎ 手動輸入、ƒ 公式、⚙ 開發攤提；紅色「!」= 公式錯誤，「?」= 沒有被算進營業淨利。
     小計那一列右邊的 **＋** 直接在那一段新增科目；拖曳 ⠿ 調整順序，放開就存。勾「顯示代碼」才會看到 b1、P8 這些代碼。
     **順序跟 Excel 損益表一樣**：「前一段 − 明細」的小計（銷貨毛利、產品貢獻、營業淨利(未扣前瞻)）排在明細下面，
     「明細加總」的群組（銷貨成本合計）排在明細上面；儀表板、GATE 報告都照這個順序。
   - **右邊一步一步**：名稱與「計入哪個小計」→ ① 這個科目怎麼算（手動輸入 / 公式計算 / 開發總投攤提）
     → ② 公式（或金額在哪裡填）→ ③ 結果：每個車系「目前 → 修改後」以及營業淨利變多少，邊打邊算，還沒儲存不影響其他頁面。
     車系個別公式、貨物稅扣除、算法說明收在「進階設定」（算法說明是整個車型共用的算法依據，不會印在報告上；報告上的說明是成本與費用頁的「報告說明」）。
   - **② 公式有兩種編輯方式**（右上角切換），存的是同一個公式：
     - **一行一項**（預設）：每一行是「＋/− 一個來源」，後面可以接好幾個「× 或 ÷ 係數」。來源可以選科目、參數、子科目合計、
       可扣除貨物稅科目合計、另一個情境（或車型）的科目、固定金額；係數可以選參數、固定百分比、固定倍數、`÷ (1 + 參數)`（含稅換未稅）或科目。
       點 ＋/− 切換加減、點 × 切換 ×/÷；**每一行右邊直接顯示這一行算出多少**，下面是合計。選單可以打字搜尋（科目名稱或代碼），每個項目旁邊有目前的數字。
       例：季Margin = ＋ 廠價(未稅) × 季Margin率；銷貨毛利 = ＋ 生產毛利 − 子科目合計；一般材料 = ＋ DE 實績的一般材料 × 1.2 倍。
     - **自由公式**：有 `IF`、`ROUND`、括號巢狀等拆不成一行一項的公式（例如貨物稅）會自動用這個。公式是一顆一顆膠囊，
       每顆底下顯示目前的值；「＋ 科目 / 參數」「ƒ 函式」插入到游標位置，數字與 `+ - * / ( ) ,` 直接用鍵盤打，
       點膠囊選取後按 Backspace 刪除、或插入新的取代它。進階使用者可以切成「用文字輸入」直接打（輸入 `[` 會跳出清單）。
   - **公式用科目名稱寫**：`[廠價(未稅)] * [季Margin率]`、`[材料成本-KD] * [關稅率]`；存檔時自動換成代碼，**科目改名不會讓公式斷掉**。
   - 新增科目還沒存之前就能試算：③ 結果直接看到加進來之後營業淨利變多少。
   - 公式語法（進階）：
     - `[名稱]`：科目名稱、系統變數（`[建議零售價]`、`[月銷量]`、`[LC總台數]`、`[構成比]`、`[攤提總台數]`…）、
       參數（`[營業稅率]`、自訂的 `[關稅率]`…，% 參數取出來自動是小數）、匯率（`[CNY匯率]`）；科目代碼（`P8`、`b1`）也可以直接打
     - 運算：`+ - * / ^ ( )`、`15%`；全形 `× ÷ − （）` 也可以直接貼上
     - 函式：`CHILDREN()` 子科目合計、`TAXDEDUCT()` 可扣除貨物稅的科目合計、`ROUND`、`ROUNDUP`、`ROUNDDOWN`、`SUM`、`MIN`、`MAX`、`ABS`、`IF`
     - 跨情境：`REF("情境", "科目代碼"[, "車系"])`，例如一般材料「以 DE 為 BASE × 1.2」（一行一項選「另一個情境的科目」再 × 1.2 倍最快）
     - 除以 0 = 0（試算初期台數還沒填時，不會整張表都變錯誤）
   - 公式語法錯誤、引用不存在的科目、循環引用會在存檔時擋下來。
   - 右上「⋯ 整份科目表」：從其他車型/範本複製、存成標準範本、恢復預設科目（刪掉的預設科目會補回來）。
   - **所有科目都是「預設」不是「內建」**：售價結構、貨物稅、季Margin、各段小計（銷貨毛利、營業淨利…）都可以改名、改算法、換父科目或刪除；
     只有會讓資料壞掉的情況會擋下（還有其他公式引用它、底下還有子科目、開發總投還指到它），先處理掉就能刪。
     預設公式跟原本 Gate F 試算表逐格相同。刪掉營業淨利(K)時，儀表板重點指標、GATE 報告、損益兩平、目標反推會改看
     損益表最底下的總計（頂層、用公式算、沒有被其他公式引用的科目；手動輸入的費用不會被當成淨利），
     所以「另建一個淨利科目再刪掉 K」數字照樣對；不同車型的淨利科目不一樣時，GATE 報告與瀑布圖的現況/目標各看自己的；
     只是想改名稱或公式的話，直接改原本的科目就好。刪掉其他預設小計（銷貨毛利…）後，用到它的地方會顯示空白。
9. **參數與匯率**（上半部參數與比率）：預設的營業稅率、銷售佣金率、季Margin率、貨物稅率、貨物稅完稅價格計算率，加上自己新增的參數
   （單位 % 或數值、預設值、說明）。所有參數（含預設的）都可以編輯單位/預設值、改名（公式裡的 [舊名稱] 與各情境的數值一起改）、刪除
   （還有公式在用時會擋下）；刪掉的預設參數不會在下次開啟時被補回來。每個情境填「全車系」值，個別車系不同才填車系欄位。
10. **參數與匯率**（下半部匯率）：1 外幣 = ? 台幣。兩個表格都改了的話，底部「儲存」/Ctrl+S 一次存兩個。

## 結果呈現

10a. **目標反推與敏感度 → 目標反推加到兩項以上（組合拳）**：照會議上的講法，每一列選一種「方式」——
    - **已知調整**：已經談好、或想試試看的調整，直接套用。可以「調 %」（材料再降 3%）、「加減」（售價 +5,000）或「調到」（銷量就是 120 台）。
    - **負責金額**：這一項要讓結果改善多少（例：採購負責 8,000 元/台），算出要調到多少；可以設最多調 ±%，做不到的差額留給補足缺口的項目。
    - **補足缺口**：剩下的缺口依列表順序補，前一項碰到「最多調 ±%」才輪到下一項（例：先靠材料最多 5%，不夠再漲價最多 2%，還不夠看銷量）。
    計算順序：先套用已知調整 → 依列表順序算負責金額 → 剩下的由補足缺口依序補；拖曳 ⠿ 調整順序。已經達到目標時補足項目不動
    （不會為了剛好等於目標往壞的方向調）；補不滿時直接寫出最多做到多少、還差多少。只有一列補足缺口、沒有上限就是單項反推。
    「組合拳範例」一鍵帶入三種方式各一的例子。
    結果列出每一項的方式、目前 → 調整後、變動 %、對結果的貢獻（依列表順序逐項加入，加總 = 總改善）、是否碰到上限，並附瀑布圖；
    「在瀑布圖工具開啟」可以再改名稱、下載 PNG。
10b. **瀑布圖工具**：四種來源 ——
    - 兩個欄位的差異：任兩個 車型×情境×車系（或加權平均）的營業淨利（或任一段小計）差在哪些科目；可選大項/明細科目、
      單台/年度/LC 總額，年度與 LC 可以拆出「銷量影響」；不能歸到單一科目的差異（自訂公式交互、尾差）單獨一根，保證接得起來。
    - 單一欄位損益：從收入一路扣到指定的小計，可以顯示中間小計。
    - 作法拆解：現況營業淨利 → 目標情境每一項改善作法的效果 → 目標，沒有寫成作法的差異單獨一根。
    - 自訂：自己輸入每一根（可從 Excel 貼上、拖曳排序）；任何一張圖都可以「轉成自訂」再修改。
    共同選項：畫到哪一列、明細程度、數值（單台/年度/LC）、金額單位（全系統共用）；排序、最多顯示幾項、小於多少併入「其他」、
    數字標籤、圖表標題收在「進階」（改過就會自動展開）；
    可以下載 PNG / SVG，或「複製表格」直接貼到 Excel。
10c. **另存成新情境**：目標反推（單項或多項）算出結果後按「另存成新情境…」，會複製目前情境的全部資料，
    再把反推的調整寫進去（銷量/售價/科目金額/開發總投等比例調整，參數與匯率直接設定），新情境的營業淨利就等於試算值；
    調整內容會記在情境備註。
10d. **情境快照（版本紀錄）**：「車型與情境」頁下方或 GATE 報告上方按「存成快照」，把當下算出來的損益（加權平均與每個車系）存一份。
    之後資料怎麼改都不影響快照；在儀表板、瀑布圖工具的情境選單裡「情境快照」一組可以直接選來比較，
    快照清單上的「跟現在比較」會直接畫出 快照 → 現在 的差異瀑布圖。快照會跟著資料包匯出，合併匯入時兩邊的快照都保留。
11. **損益儀表板**：「比較欄位」加入要比的 車型 × 情境 × 車系（或加權平均），可以跨車型並排；拖曳 ⠿ 調整欄位順序。
    子頁籤：比較欄位 / 損益表 / 圖表（科目比較、依欄位、損益結構）；右邊「瀑布圖…」選兩欄帶到瀑布圖工具看差在哪，
    選同一欄看從收入扣到營業淨利。差異數字用損益表「第二小欄 → 與基準的差異」。不常改的顯示選項在「⚙ 顯示設定」。科目名稱旁的 ƒ 顯示公式（換成科目名稱），
    格子 hover 顯示這一欄實際的計算過程；公式出錯的科目會標 ⚠。
12. **目標反推與敏感度**（只在畫面上試算，不會改到存檔的數字）
    - **目標反推**：「要讓 [營業淨利] [單台/月總額] 等於 [0] 元，[月總銷量] 要調到多少？」可以調的項目：月總銷量（攤提台數一起變）、
      建議零售價、任何一個有金額的科目、開發總投攤提、參數、匯率。常見問題一鍵帶入：損益兩平要賣幾台、要賣多少錢、材料成本要降到多少。
      只調一項達不到目標時會直接說明（例如單台變動成本已經高於售價，賣越多虧越多）。
    - **敏感度分析**：選兩項假設，每一項可以用「變動 %」（目前值 × (1 + %)）或「自訂值」（直接輸入要試算的值，例如匯率 4.5, 4.6, 4.8；
      目前的值會自動加入），產生「營業淨利」等結果的二維表，目前的數字框起來、正負以顏色區分。
      要不要放進 GATE 報告，在 GATE 報告頁勾「附敏感度分析」（表格的兩項假設與結果在這一頁設定）。
13. **GATE 報告**：選「目標/本回」「現況」「前回(選填)」，產生以下投影片（一張一頁 16:9）：
    1. 損益目標與差距摘要：現況/目標營業淨利、差距（含月效益、LC 合計）、**作法覆蓋率**（作法效果合計 ÷ 差距，依狀態分色）、損益兩平月銷量
    2. 現況 → 目標 差距拆解（瀑布圖）：哪些科目讓營業淨利變好/變差多少，並列出對應的作法。
       「在瀑布圖工具開啟」可以再改名稱、下載 PNG；「調整長條」可以把幾個科目合併成一根（填同一個名稱）、設定最多顯示幾根、影響小於多少併入「其他」（每個車型各存一份在瀏覽器）
    3. 現況與目標對照：每個科目的現況、目標、差距、對淨利影響、對應作法、說明
    4. **現況 → 作法 → 目標**（新）：營業淨利瀑布，每一項作法一根，沒有對應作法的差異單獨一根；改作法表時即時更新。
    4. **目標成本作法**：作法、科目、擔當、效果(元/台)、月效益、狀態、預計完成；合計、差距、**尚待補足**。可以拖曳排序、直接新增/修改
    5. **作法對帳**：每個科目「作法效果合計」vs「現況 → 目標實際改善」，標出作法高估、數字改善比作法多、
       有變動卻沒寫作法的科目（容差 500 元或 5%）——審議時最容易被追問的地方
    6. 細車型 FS 損益狀況（目標 / 現況）：各車系 + 加權平均 + % + 說明，版面比照審議會簡報
    7. 前回 vs 本回（有選前回時）
    8. 敏感度分析（在「目標反推與敏感度」頁勾選時）
    9. 開發總投 by 部門：模具/設備/費用、挑戰低減%、低減後小計
    - 摘要頁也會顯示**損益兩平月銷量**（只靠台數無法損益兩平時會註明）。
    - 「說明」欄可以直接點進去改，就是成本與費用頁的「報告說明」，改哪邊都是同一份。
    - 控制列的「附敏感度分析」決定要不要放敏感度分析那一張。
    - 「列印 / 存成 PDF」：瀏覽器列印時選「另存為 PDF」，每張投影片一頁。
    - 每張右上角「複製表格」：複製成 Tab 分隔文字，直接貼進 PowerPoint 或 Excel 會變成表格。

## 小技巧

- **Ctrl+S** 儲存目前頁面的修改；畫面底部的浮動列也有「儲存 / 放棄修改」。
- 表格裡任何一格都可以從 Excel 貼上一整塊數字（Ctrl+V）。
- 拖曳把手 ⠿ 可以用鍵盤：Tab 移到把手，按 Alt+↑/↓（或 ←/→）。
- 科目、車型、車系代號都不用自己編：新科目的代碼由系統配（同一個車型內不重複），改車型/車系代號用「改代號」。
