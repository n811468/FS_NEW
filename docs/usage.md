# 車型損益試算系統 — 使用說明

個人/小組使用版本（無登入權限控管、無情境鎖定）。完全離線：圖表自己產生 SVG，不載入任何外部資源。
打開方式、資料包的匯出/匯入/合併見 `../local/README.md`；資料結構見 `data-schema.md`，架構見 `architecture.md`。

## 畫面配置

左側導覽依工作流程分四組：結果呈現 → 輸入資料 → 計算設定 → 主檔。右上角固定顯示目前的車型與情境，輸入頁都以它為範圍。
頁首左邊的 ☰ 把側邊欄收成只剩圖示（滑鼠移上去顯示頁名），表格可以多出一塊寬度；再按一次展開，瀏覽器會記住。手機上 ☰ 是叫出側邊欄。
有未儲存的修改時底部浮出「儲存 / 放棄」（Ctrl+S 也可以），切頁前會先確認；成功/錯誤訊息出現在右上角。

## 開始使用

用 Chrome / Edge 雙擊 `dist/FS-local.html`。第一次打開是空的資料庫，可以：

- 「建立第一個車型」：到「車型與情境」，頁首的「下一步」會依序提示 車系 → 情境 → 銷售構成 → 成本與費用 → 開發總投；
- 「匯入資料包…」載入同事給的或自己備份的資料包（舊格式的資料包也能讀，會自動升級）；
- 「載入示範資料看看」（一個車型的 GATE F 現況與目標，含說明與作法；另一個車型的科目表不同。車型代號、名稱、數字全部是亂數產生的）。

## 建立車型與情境（主檔）

「車型與情境」一頁由上而下是車型、車系（目前車型）、情境（目前車型）、情境快照四個區塊。

1. **車型** →「＋ 新增車型」：填代號，並選擇科目表從哪裡開始 —— 標準範本，或複製一個科目結構比較接近的既有車型。
   代號之後可以用「改代號」修改，所有引用它的資料（車系、情境、科目表、作法…）會一起改。
   代號不能有空白、逗號、| 或引號。刪除車型時，底下的車系、情境（含所有輸入的數字、作法、說明）、快照與科目表會一起刪除。
2. **車系**：新增車系（標準型 / 豪華型 / 長軸版…）。拖曳 ⠿ 調整順序，放開就存，所有頁面的車系欄位照這個順序。
   車系代號在整個資料庫裡不能重複（已經用在別的車型的代號會擋下來）；刪除車系時，它在各情境的數字一起刪除。
3. **情境**：按「＋ 新增情境…」，在對話框選 GATE 別、情境性質（現況/目標）、情境名稱（預設 性質＋今天日期，改性質會跟著換）。
   可以選來源情境整批帶入（銷售構成、銷貨成本、開發總投、營業費用、費率、報告說明、改善作法可以勾選），只能在同一個車型內帶入；
   已經建好的情境用「帶入目前情境…」，同一組勾選。
   同一個 GATE 底下的情境名稱不能重複；表格裡藍底那一列是右上角目前選的情境。拖曳 ⠿ 調整情境選單的順序。
   刪除情境時，這個情境的輸入資料、作法與說明一起刪除（情境快照保留）。

## 每個情境要填的數字（輸入資料）

右上角選好車型與情境之後：

4. **銷售構成與售價**：每個車系一列。改台數 → 構成比重算；改構成比 → 依車型月總台數反推台數，兩者永遠一致。
   這裡的售價欄位是售價結構(P1~P9)公式的來源（公式裡的 `[建議零售價]`、`[廢車處理費(含稅)]`…）。
   只填構成比、沒填月台數或 LC 年限時，LC 總台數是 0、開發總投攤提會算成 0，表格下方與儀表板都會提醒。
5. **成本與費用 → 銷貨成本**（頁面上方切換 銷貨成本 / 營業費用）：列 = 成本項目、欄 = 車系，填單台金額，可選幣別（依「參數與匯率」頁的匯率換算）。
   只有計算來源是「手動輸入」的科目會出現在上半部；公式或開發總投攤提的科目列在下方唯讀，滑鼠移到金額上可以看完整計算過程。
   「報告說明」欄會直接印在 GATE 報告的「說明」欄（在報告上改也是同一份）。車系欄位的順序在「車型與情境 → 車系」拖曳。
   - **從 Excel 貼上**：在 Excel 選一塊數字複製，點表格裡的起始格按 Ctrl+V，會往右、往下依序填進去
     （千分位逗號、`(1,234)` 負數、`-` 當 0 都認得；銷售構成、開發總投等所有表格都能這樣貼）。
     填不進去的格子（不是數字、唯讀、超出表格）會標紅，提示裡也會列出內容。
   - **從 Excel 貼上整張表…**：連科目名稱與車系標題一起複製貼上，依名稱自動對應（順序不用一樣），
     先顯示對應結果讓你確認；找不到的科目可以自動新增，公式/攤提科目會略過。
   這頁新增/刪除的項目只影響目前的車型。
6. **開發總投**：跟 Excel 的「開發總投 by 部門」一樣，一個部門一列：投資金額（模具／設備／費用／總計）｜低減目標｜
   低減後（模具／設備／費用／總計）｜說明。上方是投資總額、低減後、整體低減與單台攤提。
   - **直接改格子**：一格只有一筆台幣時，點一下直接打數字（Enter 往下一格、Tab 往右一格）。部門還沒有這個大類時，
     打了金額就新增一筆，攤提落點先用這個大類的第一個科目（費用 → CMC 開發費），要改再到右側面板改。
     改過還沒儲存的格子會標黃色。
   - **右側面板**：點部門名稱（或右上角有小三角的格子、說明欄）打開。可以改部門名稱；投資明細依模具／設備／費用分組，
     每一筆有項目名稱、金額、幣別、攤提落點、分攤車系，一個大類可以有好幾筆（例：上汽開發費底下的 RMB 3000 萬、技術授權金）；
     部門說明就是 GATE 報告「開發總投 by 部門」的說明欄。一格有好幾筆或用外幣時，主表的格子右上角有小三角，要在面板裡改。
   - **低減目標**（目標情境才有）：預設整個部門一個 %；在面板切「資產、費用分開」可以各填一個（資產 = 模具＋設備），
     主表顯示「資 10%｜費 15%」。談定的是金額時，在面板「直接填談定的低減後金額」，% 會自動算。
     工具列「統一低減目標 __ % → 套用到全部部門」一次改全部。
   - **從 Excel 貼上**：在 Excel 選含表頭的整塊（部門、模具、設備、費用、總計、低減後那一組、說明）複製，貼進對話框。
     第一組模具／設備／費用是投資金額，第二組是低減後（用來反推 %），總計只用來檢查。貼上後先列出
     「要你看一下／會更新／會新增／說明會更新／不變」，確認才套用，套用後一樣要按儲存。可以選 Excel 的單位（元／千元／萬元）、
     Excel 裡沒有的部門要保留或刪除。一格有好幾筆或外幣、金額又不同時，Excel 只有合計、拆不回每一筆：
     預設先不改、列在「要你看一下」，也可以選各筆等比例調整。部門名稱要跟系統裡一樣，寫法不同會被當成新部門（預覽會標「會新增」）。
   - **每一筆明細**：工具列切換，一筆一列列出部門、大類、項目、攤提落點、分攤車系、金額、幣別，點一列打開那個部門的面板。
   - **分攤車系**：預設全車系分攤（÷ LC 總台數）；在面板裡點「全車系 ▾」勾選部分車系 = 只攤給這些車系（÷ 這些車系的攤提台數），
     對應「某些式樣、法規認證由各車系分別攤提」的情況。
   - **改低減目標**（例：原本整體低減 15%，新目標要 20%）：想先看影響，到「目標反推與敏感度 → 調整影響試算」選
     「開發總投低減目標(整體)」→「調到」20，看營業淨利等每一行變多少；定案後按「另存成新情境…」，新情境的低減% 就改成新目標，
     原始投資金額不動（舊目標的情境留著，GATE 報告可以拿來當「前回」比較）。只是改這個情境自己的數字，直接在這一頁改% 也可以。
   - **比較**：工具列切到「比較」，把幾個情境的開發總投並排（現況 vs 目標、前回 vs 本回，也可以加別的車型），一個部門一列、用部門名稱對應。
     上方每個情境一個標籤，右邊選車型＋情境按「＋ 加入」，拖曳 ⠿ 調整順序，點 ☆ 設成基準，每一欄後面接「差異」（綠色 = 對損益有利）。
     數值可以切 原始投資 / 低減後 / 低減 % / 單台攤提；列可以切 部門 / 部門 × 大類 / 大類；「部門 ▾」勾選只比某幾個部門（另列勾選部門小計）。
     表格下方有整體低減 %、攤提台數、單台攤提，單台攤提的差異拆成「投資金額影響」與「攤提台數影響」；
     「差在哪些部門」瀑布圖看 基準 → 各部門增減 → 比較欄。比較用的是已儲存的數字；情境快照沒有開發總投明細，不能選。
   - 下方「攤提落點 → 單台攤提」即時試算每個攤提落點的總額、加權單台攤提，以及每個車系各自的單台攤提；攤提基準台數也在這裡設定。
     拖曳部門名稱前的 ⠿ 調整部門順序。有金額卻沒選攤提落點的那一筆，儲存時會打開那個部門的面板提醒。
7. **成本與費用 → 營業費用**：同銷貨成本，表格依 銷售費用 / 產品貢獻前費用 / 固定營業費用 / 前瞻費用 分段顯示。

幣別選單只會出現這個情境在「參數與匯率」填了匯率的幣別；沒有外幣時，表格下方有連結帶你去填。
外幣登打的列，格子裡是原幣，「加權平均」與表尾合計已換算成台幣（滑鼠移到加權平均上可以看用的匯率）。

## 計算設定（目前車型）

8. **科目與公式**（這個車型自己的科目表）
   - **左邊長得像損益表**：科目縮排在它的小計底下，旁邊直接顯示目前情境的金額（加權平均），群組可以收合
     （售價結構預設收起來）。圖示：✎ 手動輸入、ƒ 公式、⚙ 開發攤提；紅色「!」= 公式錯誤，「?」= 沒有被算進營業淨利。
     小計那一列右邊的 **＋** 直接在那一段新增科目；拖曳 ⠿ 調整順序，放開就存。勾「顯示代碼」才會看到 b1、P8 這些代碼。
     **順序跟 Excel 損益表一樣**：「前一段 − 明細」的小計（銷貨毛利、產品貢獻、營業淨利(未扣前瞻)）排在明細下面，
     「明細加總」的群組（銷貨成本合計）排在明細上面；儀表板、GATE 報告都照這個順序。
   - **右邊一步一步**：名稱與「計入哪個小計」→ ① 這個科目怎麼算（手動輸入 / 公式計算 / 開發總投攤提）
     → ② 公式（或金額在哪裡填）→ ③ 結果：每個車系「目前 → 修改後」以及營業淨利變多少，邊打邊算，還沒儲存不影響其他頁面。
     車系個別公式、貨物稅扣除、算法說明收在「進階設定」（算法說明是整個車型共用的算法依據，不會印在報告上；報告上的說明是成本與費用頁的「報告說明」）。
   - **② 公式有兩種編輯方式**（右上角切換），存的是同一個公式：
     - **一行一項**（預設）：每一行是「＋/− 一個來源」，後面可以接好幾個「× 或 ÷ 係數」。來源可以選科目、參數、子科目合計、
       可扣除貨物稅科目合計、另一個情境（或車型）的科目、固定金額；係數可以選參數、固定百分比、固定倍數、`÷ (1 + 參數)`（含稅換未稅）或科目。
       點 ＋/− 切換加減、點 × 切換 ×/÷；**每一行右邊直接顯示這一行算出多少**，下面是合計。選單可以打字搜尋（科目名稱或代碼），每個項目旁邊有目前的數字。
       例：季Margin = ＋ 廠價(未稅) × 季Margin率；銷貨毛利 = ＋ 生產毛利 − 子科目合計；一般材料 = ＋ 前代車型實績的一般材料 × 1.2 倍。
     - **自由公式**：有 `IF`、`ROUND`、括號巢狀等拆不成一行一項的公式（例如貨物稅）會自動用這個。公式是一顆一顆膠囊，
       每顆底下顯示目前的值；「＋ 科目 / 參數」「ƒ 函式」插入到游標位置，數字與 `+ - * / ( ) ,` 直接用鍵盤打，
       點膠囊選取後按 Backspace 刪除、或插入新的取代它。進階使用者可以切成「用文字輸入」直接打（輸入 `[` 會跳出清單）。
   - **公式用科目名稱寫**：`[廠價(未稅)] * [季Margin率]`、`[材料成本-KD] * [關稅率]`；存檔時自動換成代碼，**科目改名不會讓公式斷掉**。
   - 新增科目還沒存之前就能試算：③ 結果直接看到加進來之後營業淨利變多少。
   - 公式語法（進階）：
     - `[名稱]`：科目名稱、系統變數（`[建議零售價]`、`[月銷量]`、`[LC總台數]`、`[構成比]`、`[攤提總台數]`…）、
       參數（`[營業稅率]`、自訂的 `[關稅率]`…，% 參數取出來自動是小數）、匯率（`[CNY匯率]`）；科目代碼（`P8`、`b1`）也可以直接打
     - 運算：`+ - * / ^ ( )`、`15%`；全形 `× ÷ − （）` 也可以直接貼上
     - 函式：`CHILDREN()` 子科目合計、`TAXDEDUCT()` 可扣除貨物稅的科目合計、`ROUND`、`ROUNDUP`、`ROUNDDOWN`、`SUM`、`MIN`、`MAX`、`ABS`、`IF`
     - 跨情境：`REF("情境", "科目代碼"[, "車系"])`，例如一般材料「以前代車型實績為基準 × 1.2」（一行一項選「另一個情境的科目」再 × 1.2 倍最快）。
       情境寫「車型 GATE 情境名稱」（只有一個車型有這個名稱時可以省略車型）；存檔時會換成情境代號，之後情境改名公式也不會斷
     - 除以 0 = 0（試算初期台數還沒填時，不會整張表都變錯誤）
     - 四捨五入與比較跟 Excel 一樣先取 15 位有效數字：`ROUND(1.005, 2)` = 1.01、`0.1 + 0.2 = 0.3` 成立
     - 負號比次方晚算、次方由右往左算（`-2^2` = −4、`2^3^2` = 512，跟數學課本一樣；Excel 是 4 與 64）。
       匯出 Excel 驗算檔時會自動補括號，Excel 算出來的數字跟系統相同；要 Excel 的意思請自己加括號，例如 `(-2)^2`
   - 公式語法錯誤、函式參數個數不對（例如 `ROUND(x, 1, 2)`）、引用不存在的科目、循環引用會在存檔時擋下來。
   - `REF` 引用的情境自己有算不出來的科目（例如兩個情境互相引用）時，這一格會標成錯誤，不會默默用 0 代替。
   - 右上「⋯ 整份科目表」：從其他車型/範本複製、存成標準範本、恢復預設科目（刪掉的預設科目會補回來）。
   - **所有科目都是「預設」不是「內建」**：售價結構、貨物稅、季Margin、各段小計（銷貨毛利、營業淨利…）都可以改名、改算法、換父科目或刪除；
     只有會讓資料壞掉的情況會擋下（還有其他公式引用它、底下還有子科目、開發總投還指到它），先處理掉就能刪。
     預設公式跟原本 Gate F 試算表逐格相同。刪掉營業淨利(K)時，儀表板重點指標、GATE 報告、損益兩平、目標反推會改看
     損益表最底下的總計（頂層、用公式算、沒有被其他公式引用的科目；手動輸入的費用不會被當成淨利），
     所以「另建一個淨利科目再刪掉 K」數字照樣對；不同車型的淨利科目不一樣時，GATE 報告與瀑布圖的現況/目標各看自己的；
     只是想改名稱或公式的話，直接改原本的科目就好。刪掉其他預設小計（銷貨毛利…）後，用到它的地方會顯示空白。
9. **參數與匯率**（上半部參數與比率）：預設的營業稅率、銷售佣金率、季Margin率、貨物稅率、貨物稅完稅價格計算率，加上自己新增的參數
   （單位 % 或數值、預設值、說明）。所有參數（含預設的）都可以編輯單位/預設值、改名（公式裡的 [舊名稱] 與各情境的數值一起改）、刪除
   （還有公式在用時會擋下）；刪掉的預設參數不會在下次開啟時被補回來。
   參數的名稱、單位、預設值所有車型共用；**數值是每個情境各填一份**，填「全車系」值，個別車系不同才填車系欄位。
   參數旁標「沿用預設值」= 這個情境沒填、用預設值；標「未填 = 0」= 沒填也沒有預設值，公式會當成 0。
   在一個情境填了沒有預設值的參數，而同車型的其他情境還沒填時，存檔後會提醒（不然現況 → 目標的比較會多出一段差異）。
10. **參數與匯率**（下半部匯率）：1 外幣 = ? 台幣，也是每個情境各填一份。兩個表格都改了的話，底部「儲存」/Ctrl+S 一次存兩個。

## 結果呈現

11. **損益儀表板**：「比較欄位」加入要比的 車型 × 情境 × 車系（或加權平均），可以跨車型並排；拖曳 ⠿ 調整欄位順序。
    子頁籤：比較欄位 / 損益表 / 圖表（科目比較、依欄位、損益結構）；右邊「瀑布圖…」選兩欄帶到瀑布圖工具看差在哪，
    選同一欄看從收入扣到營業淨利。差異數字用損益表「第二小欄 → 與基準的差異」。不常改的顯示選項在「⚙ 顯示設定」。
    某一欄算不出來（例：那個車系在這個情境還沒有銷售構成）時只略過那一欄，上方說明是哪一欄、為什麼，按「從比較欄位移除」一鍵拿掉，其他欄位照常顯示。
    科目名稱旁的 ƒ 顯示公式（換成科目名稱），格子 hover 顯示這一欄實際的計算過程；公式出錯的科目會標 ⚠。
    金額單位（元 / 千元 / 萬元）全系統共用，在儀表板、GATE 報告或瀑布圖工具任何一頁改，其他頁跟著變。
    第二小欄選「與基準的差異」時還沒設比較基準，會先用第一欄。「匯出 CSV」可以下載 .csv 檔（Excel 直接打開）或複製到剪貼簿。
12. **目標反推與敏感度**（只在畫面上試算，不會改到存檔的數字）
    - **目標反推**：「要讓 [營業淨利] [單台/月總額] 等於 [0] 元，[月總銷量] 要調到多少？」可以調的項目：月總銷量（攤提台數一起變）、
      建議零售價、任何一個有金額的科目、開發總投攤提、開發總投低減目標（目標情境才有）、參數、匯率。常見問題一鍵帶入：損益兩平要賣幾台、要賣多少錢、材料成本要降到多少。
      只調一項達不到目標時會直接說明（例如單台變動成本已經高於售價，賣越多虧越多）。
    - **組合拳**：按「＋ 加一個項目」加到兩項以上，每一列選一種「方式」——
      - **已知調整**：已經談好、或想試試看的調整，直接套用。可以「調 %」（材料再降 3%）、「加減」（售價 +5,000）或「調到」（銷量就是 120 台）。
      - **負責金額**：這一項要讓結果改善多少（例：採購負責 8,000 元/台），算出要調到多少；可以設最多調 ±%，做不到的差額留給補足缺口的項目。
      - **補足缺口**：剩下的缺口依列表順序補，前一項碰到「最多調 ±%」才輪到下一項（例：先靠材料最多 5%，不夠再漲價最多 2%，還不夠看銷量）。
      計算順序：先套用已知調整 → 依列表順序算負責金額 → 剩下的由補足缺口依序補；拖曳 ⠿ 調整順序。已經達到目標時補足項目不動
      （不會為了剛好等於目標往壞的方向調）；補不滿時直接寫出最多做到多少、還差多少。「組合拳範例」一鍵帶入三種方式各一的例子。
      結果列出每一項的方式、目前 → 調整後、變動 %、對結果的貢獻（依列表順序逐項加入，加總 = 總改善）、是否碰到上限，並附瀑布圖。
    - **另存成新情境**：算出結果後按「另存成新情境…」，會複製目前情境的全部資料，再把反推的調整寫進去
      （銷量/售價/科目金額等比例調整，參數與匯率直接設定），新情境的營業淨利就等於試算值；調整內容會記在情境備註。
      開發總投的調整寫進各列的挑戰低減目標%（原始投資金額不動，例：低減 15% 的列再 × 80/85 → 20%）；
      新情境是現況（不套低減）、或調到比原始金額還高時，才直接改金額。
      「開發總投低減目標(整體)」= 1 − 低減後合計 ÷ 原始合計；調到新的 % 時，各列的低減後金額等比例調整（各列原本的低減% 不同時，各自換算）。
    - **調整影響試算**：反過來問「某一項調整多少，結果會變多少」。每一列選一個調整項目，用「調 %」「加減」或「調到」填調整幅度
      （例：材料成本降 3%、售價 +10,000），按「試算」列出整張損益表每一行的 目前 → 調整後、變動、變動 %，營業淨利那一行標粗。
      可以切單台（加權平均）/ 月總額、只列有變動的科目；加到兩項以上時，每一項另外一欄列出它造成的變動（依列表順序逐項加入，加總 = 總變動）。
      結果一樣可以「另存成新情境…」。
    - **敏感度分析**：選兩項假設，每一項可以用「變動 %」（目前值 × (1 + %)）或「自訂值」（直接輸入要試算的值，例如匯率 4.5, 4.6, 4.8；
      目前的值會自動加入），產生「營業淨利」等結果的二維表，目前的數字框起來、正負以顏色區分。看單台的結果時，銷量 0 台那一格顯示「—」（算不出單台）。
      要不要放進 GATE 報告，在 GATE 報告頁勾「附敏感度分析」（表格的兩項假設與結果在這一頁設定）。
13. **瀑布圖工具**：四種來源 ——
    - 兩個欄位的差異：任兩個 車型×情境×車系（或加權平均）的營業淨利（或任一段小計）差在哪些科目；可選明細科目/大項、
      單台/年度/LC 總額，年度與 LC 可以拆出「銷量影響」；不能歸到單一科目的差異（自訂公式交互、尾差）單獨一根，保證接得起來。
    - 單一欄位損益：從收入一路扣到指定的小計，可以顯示中間小計。
    - 原因拆解：選起點情境、終點情境、要看的科目（營業淨利或任何一個科目，例如材料成本-KD）。起點、終點是這個科目在兩個情境的數字，
      中間每一根是自己填的原因（名稱、優化/惡化、金額元/台），原因加總跟實際變動對不起來的部分自動變成「其他」。
      原因就在瀑布圖工具下方的表格直接填、按「儲存原因」，存在終點情境，跟 GATE 報告「目標成本作法」是同一份清單（效果正數 = 優化、負數 = 惡化）。
      看成本、費用科目時，成本變少是綠色、變多是紅色。GATE 報告「作法對帳」每一列的「瀑布」可以直接開成這個科目的原因拆解。
    - 自訂：自己輸入每一根（可從 Excel 貼上、拖曳排序）；任何一張圖都可以「轉成自訂」再修改。
    共同選項：畫到哪一列、明細程度、數值（單台/年度/LC）、金額單位；排序、最多顯示幾項、小於多少併入「其他」、
    數字標籤、縱軸是否一律從 0 開始、圖表標題收在「進階」（改過就會自動展開）。
    差異只佔整根一小段時（例：15 萬 → 15.9 萬），縱軸會自動放大，圖上註明「縱軸未從 0 開始」；要從 0 畫就在進階勾選。
    可以下載 PNG / SVG，或「複製表格」直接貼到 Excel。
14. **情境快照（版本紀錄）**：「車型與情境」頁下方或 GATE 報告上方按「存成快照」，把當下算出來的損益（加權平均與每個車系）存一份。
    之後資料怎麼改都不影響快照；在儀表板、瀑布圖工具的情境選單裡「情境快照」一組可以直接選來比較，
    快照清單上的「跟現在比較」會直接畫出 快照 → 現在 的差異瀑布圖。快照會跟著資料包匯出，合併匯入時兩邊的快照都保留。
15. **GATE 報告**：選「目標/本回」「現況」「前回(選填)」，產生以下投影片（一張一頁 16:9）：
    1. 損益目標與差距摘要：現況/目標營業淨利、差距（含月效益、LC 合計）、**作法覆蓋率**（作法效果合計 ÷ 差距，依狀態分色）、
       **損益兩平月銷量**（只靠台數無法損益兩平時會註明）
    2. 現況 → 目標 差距拆解（瀑布圖）：哪些科目讓營業淨利變好/變差多少，並列出對應的作法。
       「在瀑布圖工具開啟」可以再改名稱、下載 PNG；「調整長條」可以把幾個科目合併成一根（填同一個名稱）、設定最多顯示幾根、影響小於多少併入「其他」（每個車型各存一份在瀏覽器）
    3. 現況與目標對照：每個科目的現況、目標、差距（綠色 = 對淨利有利、紅色 = 不利）、對應作法、說明
    4. **目標成本作法**：作法、科目、擔當、效果(元/台)、月效益、狀態、預計完成；合計、差距、**尚待補足**。可以拖曳排序、直接新增/修改。
       效果是對營業淨利的單台影響：成本降 1 萬填 10000（正數 = 改善），規格追加等惡化填負數
    5. **現況 → 作法 → 目標**：營業淨利瀑布，每一項作法一根，沒有對應作法的差異單獨一根；改作法表時即時更新
    6. **作法對帳**：每個科目「作法效果合計」vs「現況 → 目標實際改善」，標出作法高估、數字改善比作法多、
       有變動卻沒寫作法、金額對得上但正負號相反的科目（容差 500 元或 5%）——審議時最容易被追問的地方
    7. 細車型 FS 損益狀況（目標 / 現況）：各車系 + 加權平均 + % + 說明，版面比照審議會簡報
    8. 前回 vs 本回（有選前回時）：前回可以選一般情境，也可以選情境快照（例如上次審議前存的「審議版」）
    9. 敏感度分析（勾「附敏感度分析」時）
    10. 開發總投 by 部門：模具/設備/費用、挑戰低減%、低減後小計
    11. 開發總投比較（有選現況或前回時）：各部門 前回 / 現況 / 本回原始 / 挑戰低減% / 本回低減後 與差異，最下面是單台攤提；前回是情境快照時只比現況
    - 「說明」欄可以直接點進去改，就是成本與費用頁的「報告說明」，改哪邊都是同一份。
    - 「列印 / 存成 PDF」：瀏覽器列印時選「另存為 PDF」，每張投影片一頁。

16. **Excel 驗算檔**：在 Excel 裡用系統建好的公式與數字重算一次，確認系統算的跟 Excel 一樣，也方便給沒有這套系統的人核對。
    儀表板工具列「匯出 Excel 驗算檔」（比較欄位有好幾個情境時先選一個），或工具列「匯出 ▾ → Excel 驗算檔（目前情境）」。一個情境一個檔，包含：
    - **說明**：驗算結果（「✓ 全部一致」或「✗ 有 N 個科目不一致」）、營業淨利 Excel 重算 vs 系統、容差（預設 0.01 元，可以改）、顏色與翻譯規則。
    - **輸入**：銷售構成與售價、參數（% 參數存成小數）、匯率、系統變數（LC總台數、構成比、攤提總台數…，都是公式）、
      手動輸入的成本與費用（外幣是原幣，損益試算再 × 匯率）、跨情境引用 REF 的數字。藍字黃底 = 輸入值，「共用」欄是全車系的值，車系沒有個別值時引用它。
    - **開發總投**：每一筆的台幣金額、低減後、各車系單台攤提（只攤給部分車系的 ÷ 那幾個車系的攤提台數），最下面依攤提落點 SUMIF 彙總。
    - **損益試算**：科目 × 車系，每一格都是 Excel 公式，由「科目與公式」頁的公式翻譯（科目 → 同一欄的格子、[名稱] → 輸入表的格子、
      `CHILDREN()` → SUM、除法 → `IF(分母=0,0,…)`，因為系統的除以 0 = 0）；加權平均 = SUMPRODUCT(各車系, 構成比)。
    - **驗算**：匯出當下的系統數字（固定值）與 Excel 重算的差異，逐格比對，超過容差標紅。
    - **公式區**：每個科目一列（車系有個別公式時每一種各一列）：系統公式（科目名稱）、存檔的公式、Excel 公式（`FORMULATEXT`，跟著損益試算表變）、
      對照說明、驗算結果；最下面是名稱對照表：公式裡每個 `[名稱]` 引用輸入表的哪一格。
    打開時 Excel 會重算全部公式。改「輸入」或「開發總投」的藍字就能在 Excel 裡試算，驗算頁會顯示跟匯出當時的差異（那是改動的影響，不是錯誤）。

    **改公式、改科目之後的檢查**：「驗算」一致只代表系統照現在的公式算對了；公式本身改壞（小計少算一段、科目沒掛進小計、同一筆成本扣兩次），
    Excel 照同一個公式算出來也會「一致」。所以驗算檔另外有四項不依賴目前公式的檢查，結果列在「說明」頁：
    - **結構檢查**：用系統預設的算法（A = P8 + P9、C = A − B、E = C − Σ子科目…，以及 營業淨利 = 收入 − 全部成本費用明細）在 Excel 另外算一次各段小計，跟損益試算比。
    - **科目影響**：系統把每個明細科目逐一 +1,000 元重算，看營業淨利變多少。成本費用應該是 −1；0 = 沒有算進營業淨利、−2 = 重複計算、正負號反了 = 掛錯段落。
      可扣除貨物稅的科目（廣宣、促銷、批標售、季Margin）會連動貨物稅，約 −0.88 是正常的。
    - **跟系統預設比較**：公式區最右邊兩欄列出系統預設的算法，以及這個科目是否「公式跟預設不同」「計算來源改過」「所屬小計改過」「新增的科目」，審核時只要看這幾條。
    - **變動檢查**（選了快照才有）：改公式、科目之前先存情境快照，匯出時在對話框「跟快照比」選它。每個科目列出 快照 → 現在 的差異與公式有沒有改，
      「⚠ 公式沒改、數字卻變了」代表上游被改到（或輸入有改），要特別確認。
    建議流程：改公式前「存成快照」→ 改公式、科目 → 匯出驗算檔並選那個快照 → 看「說明」頁的四項檢查，標紅、標黃的逐一確認是不是預期的。

    **發現錯誤怎麼辦**：
    - 「驗算」頁不一致（沒改過輸入）：是系統計算的問題，使用者改不了，把驗算檔和「匯出 ▾ → 匯出情境」的資料包交給系統維護人員。
    - 其他四項標紅：是科目表的設定（公式、所屬小計）有問題。每一項旁邊都有「怎麼修正」，寫出要到「科目與公式」點哪個科目、改成什麼；
      「科目影響」會列出是哪些科目重複算到它，「變動檢查」會列出它上游哪些科目變了。
    - 可以在系統裡改，也可以直接在驗算檔裡改（「損益試算」改公式，「輸入」「開發總投」改藍字），再匯入回系統。

17. **從 Excel 驗算檔匯入**：儀表板工具列「從 Excel 匯入…」、「科目與公式」頁右上「⋯ 整份科目表」，或工具列「更多… → 從 Excel 驗算檔匯入…」，選改過的驗算檔。
    - 只匯入跟匯出當時不一樣的格子：「損益試算」的公式、「輸入」的藍字（售價、銷量、參數、匯率、成本金額、攤提基準台數）、「開發總投」的金額與低減目標。
    - 先顯示預覽：「公式」「輸入數字」兩組列出 現在 → 匯入後，勾選後按「匯入勾選的項目」才存；匯入前系統會自動存一份快照「匯入 Excel 前」。
    - 公式翻回系統的寫法：同一個車系欄的科目格子 → 科目、「輸入」的格子 → [參數]/[系統變數]、SUM(子科目) → CHILDREN()、IF(分母=0,0,…) → 除法。
      只有部分車系改了，存成那幾個車系的個別公式。科目表是整個車型共用，改公式會影響這個車型的所有情境。
    - 「無法匯入」會列出原因：用了系統沒有的函式（只能用 SUM、ROUND、ROUNDUP、ROUNDDOWN、MIN、MAX、ABS、IF）、引用別的車系欄、
      引用三張表以外的格子、改了加權平均欄或跨情境引用的數字。這些格子不會存。
    - 匯出之後系統裡同一個地方也改過時，標「匯出後系統也改過」，預設不勾，確認要用 Excel 的版本蓋掉才勾。
    - 不能在 Excel 新增科目：要先在系統新增科目，再匯出、改公式、匯入。

## 小技巧

- **Ctrl+S** 儲存目前頁面的修改；畫面底部的浮動列也有「儲存 / 放棄修改」。有修改還沒存就切頁時會先問：要保留就按「留在這一頁」再存。
- 表格裡任何一格都可以從 Excel 貼上一整塊數字（Ctrl+V），全形數字也認得。
- 表格裡跟 Excel 一樣：Enter / ↓ 到下一列、Shift+Enter / ↑ 到上一列（不會改到數字）。
- 拖曳把手 ⠿ 可以用鍵盤：Tab 移到把手，按 Alt+↑/↓（或 ←/→）。
- 科目、車型、車系代號都不用自己編：新科目的代碼由系統配（同一個車型內不重複），改車型/車系代號用「改代號」。
