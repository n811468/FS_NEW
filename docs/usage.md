# 車型損益試算系統 v2 — 使用說明

個人/小組使用版本（無登入權限控管、無情境鎖定）。完全離線：圖表自己產生 SVG，不載入任何外部資源。
打開方式、資料包的匯出/匯入/合併見 `../local/README.md`；資料結構見 `data-schema.md`，架構見 `architecture.md`。

## v2 改了什麼

| 以前的痛點 | v2 的做法 |
|---|---|
| 介面老舊、找不到東西 | 左側導覽依工作流程分四組（結果呈現 → 輸入資料 → 計算設定 → 主檔），右上角固定顯示目前的車型/情境；有未儲存的修改時底部浮出「儲存 / 放棄」(Ctrl+S 也可以)，切頁前會先確認；成功/錯誤訊息改成右上角提示；確認與輸入改用對話框 |
| 科目設定很難操作；計算來源、公式寫死 | 新的「科目與公式」頁：左邊科目樹、右邊編輯器。每個科目選一種**計算來源**（手動輸入 / 公式 / 開發總投攤提），公式可以自由寫，邊打邊檢查、邊看各車系試算結果 |
| 科目在不同車型間差很多，拿一個車型當基底誤差很大 | **每個車型各自一份科目表**。新車型可以選從標準範本或從某個既有車型複製；同一個車型裡個別車系算法不同時，還可以設「車系個別公式」；開發總投可以只攤給部分車系 |
| 簡報上的「現況與目標差距、作法」要另外整理 | 新的「GATE 報告」頁：差距摘要、差距拆解瀑布圖、現況 vs 目標對照(含對應作法與說明)、目標成本作法清單、細車型 FS、前回 vs 本回、開發總投 by 部門，一頁一張投影片，可列印/存 PDF、複製表格貼進 PowerPoint |
| 調整順序要一格一格按 ▲▼ | 全系統改成拖曳 ⠿ 把手（放開就生效），鍵盤也可以：把手取得焦點後 Alt+↑/↓ |

## 開始使用

用 Chrome / Edge 雙擊 `dist/FS-local.html`。第一次打開是空的資料庫，可以：

- 「匯入資料包…」載入同事給的或自己備份的資料包（v1 的資料包也能讀，會自動升級）；
- 「更多…」→「載入示範資料」先看看（DA Gate F 現況與目標，含說明與作法；另一個車型 DE 的科目表跟 DA 不同）；
- 或直接從「車型主檔」開始建立。

## 建立車型與情境（主檔）

1. **車型主檔** →「＋ 新增車型」：填代號，並選擇科目表從哪裡開始 —— 標準範本，或複製一個科目結構比較接近的既有車型。
   代號之後可以用「改代號」修改，所有引用它的資料（車系、情境、科目表、作法…）會一起改。
2. **車系設定**：新增車系（3人貨車 / 9人客貨車…）。拖曳 ⠿ 調整順序，放開就存，所有頁面的車系欄位照這個順序。
3. **情境設定**：選 GATE 別、情境名稱、情境性質（現況/目標）。新增情境時可以選來源情境整批帶入
   （銷售構成、銷貨成本、開發總投、營業費用、費率、科目說明、改善作法可以勾選），只能在同一個車型內帶入。
   拖曳 ⠿ 調整情境選單的順序。

## 每個情境要填的數字（輸入資料）

右上角選好車型與情境之後：

4. **銷售構成與售價**：每個車系一列。改台數 → 構成比重算；改構成比 → 依車型月總台數反推台數，兩者永遠一致。
   這裡的售價欄位是售價結構(P1~P9)公式的來源（公式裡的 `[建議零售價]`、`[廢車處理費(含稅)]`…）。
5. **銷貨成本**：列 = 成本項目、欄 = 車系，填單台金額，可選幣別（依匯率設定換算）。
   只有計算來源是「手動輸入」的科目會出現在上半部；公式或開發總投攤提的科目列在下方唯讀，滑鼠移到金額上可以看完整計算過程。
   「說明」欄會直接帶到 GATE 報告上（跟報告上的說明是同一份）。上方的「車系順序」可以直接拖曳。
   這頁新增/刪除的項目只影響目前的車型。
6. **開發總投**：每一列 部門 → 大類（設備/模具/費用）→ 攤提落點 → 金額。
   - **分攤車系**：預設全車系分攤（÷ LC 總台數）；勾選部分車系 = 只攤給這些車系（÷ 這些車系的攤提台數），
     對應簡報上「中低規式樣及 TNCAP 由各車型分別攤提」的情況。
   - 目標情境才有挑戰低減目標%，可以直接改低減後金額反推%。
   - 下方表格即時試算每個攤提落點的總額、加權單台攤提，以及每個車系各自的單台攤提。拖曳 ⠿ 調整列順序。
7. **營業費用**：同銷貨成本，科目分銷售費用 / 產品貢獻前費用 / 固定營業費用 / 前瞻費用。

## 計算設定（目前車型）

8. **科目與公式**（這個車型自己的科目表）
   - 左邊科目樹：售價結構一段、損益一段，子科目縮排在它的小計底下。拖曳 ⠿ 調整同一層的順序，放開就存。
     有公式錯誤的科目標紅色「!」，沒有被任何小計算進營業淨利的科目標「?」。
   - 右邊編輯器：名稱、計入哪個小計(父科目)、**計算來源**、貨物稅完稅價格可扣除、科目說明。
   - **公式**語法貼近 Excel：
     - 科目代碼直接打：`P8`、`b1`、`B`
     - `[名稱]`：系統變數（`[建議零售價]`、`[月銷量]`、`[LC總台數]`、`[構成比]`、`[攤提總台數]`…）、
       參數（`[營業稅率]`、自訂的 `[關稅率]`…，% 參數取出來自動是小數）、匯率（`[CNY匯率]`）、或同一張科目表的科目名稱（`[材料成本-KD]`）
     - 運算：`+ - * / ^ ( )`、`15%`；全形 `× ÷ − （）` 也可以直接貼上
     - 函式：`CHILDREN()` 子科目合計、`TAXDEDUCT()` 可扣除貨物稅的科目合計、`ROUND(x[,位數])`、`ROUNDUP`、`ROUNDDOWN`、`SUM`、`MIN`、`MAX`、`ABS`、`IF(條件,成立,不成立)`
     - 跨情境：`REF("情境ID或「車型 GATE 名稱」", "科目代碼"[, "車系ID"])`，例如一般材料「以 DE 為 BASE × 1.2」：
       `REF("DE GATE Z 實績", "b4") * 1.2`。沒指定車系時，對方情境有同一個車系就取同一個，否則取加權平均。
     - 除以 0 = 0（試算初期台數還沒填時，不會整張表都變錯誤）
   - 下方的插入面板可以點選科目、變數、參數、函式插入到游標位置；公式下面會用科目名稱顯示「看得懂的版本」。
   - **即時試算**：每次修改都會用目前情境試算，列出每個車系這個科目與營業淨利「目前 → 修改後」的值與計算過程，
     確定沒問題再儲存。公式語法錯誤、引用不存在的科目、循環引用會在存檔時擋下來。
   - **車系個別公式**：同一個車型裡某個車系算法不同時才填，留白 = 照科目的計算來源。
   - 上方按鈕：「從其他車型/範本複製…」（整份換掉）、「存成標準範本」（之後新建車型的預設）、「恢復內建預設」。
   - 內建的售價結構、貨物稅、季Margin、各段小計(`B = CHILDREN()`、`E = C - CHILDREN()`…)全部只是預設公式，可以直接改。
     標準範本的預設公式跟原本 Gate F 試算表逐格相同（`tools/verify-gatef.js` 驗算 317 格）。
9. **參數與比率**：內建的營業稅率、銷售佣金率、季Margin率、貨物稅率、貨物稅完稅價格計算率，加上自己新增的參數
   （單位 % 或數值、預設值、說明）。每個情境填「全車系」值，個別車系不同才填車系欄位。
10. **匯率設定**：1 外幣 = ? 台幣。

## 結果呈現

11. **損益儀表板**：「比較欄位」加入要比的 車型 × 情境 × 車系（或加權平均），可以跨車型並排；拖曳 ⠿ 調整欄位順序。
    損益表、重點指標、四種圖表、差異比較跟 v1 相同；科目名稱旁的 ƒ 顯示公式（換成科目名稱），
    格子 hover 顯示這一欄實際的計算過程；公式出錯的科目會標 ⚠。
12. **GATE 報告**：選「目標/本回」「現況」「前回(選填)」，產生以下投影片（一張一頁 16:9）：
    1. 損益目標與差距摘要：現況/目標營業淨利、差距（含月效益、LC 合計）、**作法覆蓋率**（作法效果合計 ÷ 差距，依狀態分色）
    2. 現況 → 目標 差距拆解（瀑布圖）：哪些科目讓營業淨利變好/變差多少，並列出對應的作法
    3. 現況與目標對照：每個科目的現況、目標、差距、對淨利影響、對應作法、說明
    4. **目標成本作法**：作法、科目、擔當、效果(元/台)、月效益、狀態、預計完成；合計、差距、**尚待補足**。可以拖曳排序、直接新增/修改
    5. 細車型 FS 損益狀況（目標 / 現況）：各車系 + 加權平均 + % + 說明，版面比照審議會簡報
    6. 前回 vs 本回（有選前回時）
    7. 開發總投 by 部門：模具/設備/費用、挑戰低減%、低減後小計
    - 「說明」欄可以直接點進去改，存回該情境的科目說明（銷貨成本/營業費用頁的說明欄是同一份）。
    - 「列印 / 存成 PDF」：瀏覽器列印時選「另存為 PDF」，每張投影片一頁。
    - 每張右上角「複製表格」：複製成 Tab 分隔文字，直接貼進 PowerPoint 或 Excel 會變成表格。

## 小技巧

- **Ctrl+S** 儲存目前頁面的修改；畫面底部的浮動列也有「儲存 / 放棄修改」。
- 拖曳把手 ⠿ 可以用鍵盤：Tab 移到把手，按 Alt+↑/↓（或 ←/→）。
- 科目、車型、車系代號都不用自己編：新科目的代碼由系統配（同一個車型內不重複），改車型/車系代號用「改代號」。
