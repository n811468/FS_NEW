車型損益試算系統使用手冊

從打開檔案、建立車型與情境、輸入數字，到看損益、做 GATE 報告，最後匯出 Excel 驗算檔確認每一個數字。書中的畫面全部是系統實際操作的截圖，數字來自內建的示範資料（車型代號與金額都是亂數產生的）。

車型與情境→銷售構成與售價→成本與費用→開發總投→科目與公式→儀表板・GATE 報告→Excel 驗算檔

1開始使用

系統是一個 HTML 檔（FS-local.html），用 Chrome 或 Edge 雙擊就能用。不需要網路、帳號或安裝，資料只存在自己電腦的瀏覽器裡。

打開與載入資料

第一次打開是空的資料庫，畫面上方的藍色提示列有三個起點：

  • 建立第一個車型：到「車型與情境」，頁首的「下一步」會依序提示 車系 → 情境 → 銷售構成 → 成本與費用 → 開發總投。
  • 匯入資料包…：讀進 JSON 資料包（舊格式也能讀，會自動升級，數字不變）。
  • 載入示範資料看看：兩個車型，其中一個有 GATE F 的現況與目標情境、作法與說明。本手冊的截圖都用這組資料。

畫面配置

  • 左側導覽：結果呈現（儀表板、GATE 報告、目標反推、瀑布圖）→ 輸入資料（目前情境）→ 計算設定（科目與公式、參數與匯率）→ 主檔（車型與情境）。
  • 頁首左邊的 ☰ 把側邊欄收成只剩圖示，表格多一塊寬度；瀏覽器會記住。
  • 有未儲存的修改時，畫面底部浮出「儲存 / 放棄修改」，Ctrl+S 也能存；切頁前會先確認。

備份與交換

選項內容用途
匯出全部（備份）整份資料庫這是備份，請定期存到共用資料夾
匯出車型（含所有情境）上方選的車型：車系、所有情境、科目表交給同事「合併匯入」，對方的這個車型整個換成這一包
匯出情境（只有這一個）上方選的一個情境交給同事合併，對方只新增或更新這個情境
Excel 驗算檔（目前情境）輸入數字＋每個科目的 Excel 公式在 Excel 裡重算、逐格比對系統數字；不能匯入
資料只在這台電腦的瀏覽器裡。清除瀏覽資料或換電腦就會消失。工具列會提醒「有修改還沒整份備份」，看到就做一次「匯出全部」。

2車型、車系與情境

「車型與情境」一頁由上而下是車型、車系、情境、情境快照四個區塊。車型是最上層的單位，每個車型各自有一份科目表。

新增車型與車系

  1. 按 ＋ 新增車型，填車型代號（不能有空白、逗號、| 或引號）。
  2. 選科目表從哪裡開始：標準範本，或複製一個科目結構比較接近的既有車型。
  3. 在「車系」區塊新增車系（標準型、豪華型、長軸版…），拖曳 ⠿ 調整順序，所有頁面的車系欄位都照這個順序。

新增情境

情境是「某個 GATE 的某一版數字」，例如 GATE F 現況、GATE F 目標。目標情境才有開發總投的挑戰低減目標。

  1. 按 ＋ 新增情境…，選 GATE 別、情境性質（現況／目標），情境名稱預設是 性質＋今天日期。
  2. 要以既有情境為基礎時，選來源情境並勾選要帶入的資料：銷售構成、銷貨成本、開發總投、營業費用、費率、報告說明、改善作法。只能在同一個車型內帶入。
  3. 已經建好的情境用 帶入目前情境…，同一組勾選。表格裡藍底那一列是右上角目前選的情境。

情境快照

按 把目前情境存成快照，把當下算出來的損益（加權平均與每個車系）存一份，之後資料怎麼改都不影響它。儀表板、瀑布圖工具的情境選單裡「情境快照」一組可以直接拿來比較，GATE 報告的「前回」也可以選快照。

3輸入資料

先在右上角選好車型與情境，再依序填銷售構成與售價、成本與費用、開發總投。每個表格都可以從 Excel 選一塊數字複製，點起始格按 Ctrl+V 整塊貼上。

銷售構成與售價

每個車系一列。改台數時構成比重算；改構成比時依車型月總台數反推台數，兩者永遠一致。這裡的售價欄位是售價結構（P1~P9）公式的來源，例如公式裡的 [建議零售價]、[廢車處理費(含稅)]。

成本與費用

頁面上方切換 銷貨成本／營業費用。列是成本項目、欄是車系，填單台金額，可以選幣別（依「參數與匯率」頁的匯率換算）。

貼上的格式：千分位逗號、(1,234) 負數、- 當 0、全形數字都認得。填不進去的格子（不是數字、唯讀、超出表格）會標紅，提示裡列出內容。

開發總投

跟 Excel 的「開發總投 by 部門」一樣，一個部門一列：投資金額（模具／設備／費用／總計）｜低減目標｜低減後｜說明。上方是投資總額、低減後、整體低減與單台攤提。

  1. 點部門名稱打開右側面板：可以改部門名稱，投資明細依模具／設備／費用分組，每一筆有項目、金額、幣別、攤提落點、分攤車系。
  2. 低減目標預設整個部門一個 %；切「資產、費用分開」可以各填一個。談定的是金額時，直接填低減後金額，% 自動算。
  3. 預設全車系分攤（÷ LC 總台數）；點「全車系 ▾」勾選部分車系，就只攤給那幾個車系（÷ 這些車系的攤提台數）。
  4. 改完按 儲存。有金額卻沒選攤提落點的那一筆，儲存時會打開那個部門的面板提醒。

4科目與公式

每個車型有自己的科目表。每個科目選一種計算來源：手動輸入、公式計算、開發總投攤提。預設公式跟原本 Gate F 試算表逐格相同，全部都可以改。

科目表

  • 小計那一列右邊的 ＋ 直接在那一段新增科目；拖曳 ⠿ 調整順序，放開就存。
  • 順序跟 Excel 損益表一樣：「前一段 − 明細」的小計（銷貨毛利、產品貢獻）排在明細下面，「明細加總」的群組（銷貨成本合計）排在明細上面。
  • 右上「⋯ 整份科目表」：從其他車型或範本複製、存成標準範本、恢復預設科目。

編輯公式

點左邊一個科目，右邊一步一步設定：名稱與「計入哪個小計」→ ① 怎麼算 → ② 公式 → ③ 每個車系「目前 → 修改後」與營業淨利變多少。還沒儲存不影響其他頁面。

寫法意思例子
[名稱]科目名稱、系統變數、參數（% 參數取出來是小數）、匯率[廠價(未稅)] * [季Margin率]
科目代碼直接打代碼也可以P5 - P6 - P7
+ - * / ^ ( )、15%運算；全形 × ÷ − （）也可以[一般材料] * 1.2
CHILDREN()子科目合計[生產毛利] - CHILDREN()
TAXDEDUCT()勾「貨物稅完稅價格可扣除」的科目合計貨物稅公式
ROUND ROUNDUP ROUNDDOWN SUM MIN MAX ABS IF跟 Excel 同名同義ROUND([實際零售價(含稅)] * [營業稅率] / (1 + [營業稅率]))
REF("情境", "科目"[, "車系"])引用另一個情境（可以是別的車型）的科目REF("S3 GATE E 實績", "b4") * 1.2
除以 0 = 0。試算初期台數還沒填時，整張表不會因此全部變成錯誤。公式語法錯誤、引用不存在的科目、循環引用會在存檔時擋下來。

參數與匯率

  • 標「沿用預設值」= 這個情境沒填，用預設值；標「未填 = 0」= 沒填也沒有預設值，公式會當成 0。
  • 幣別選單只會出現這個情境填了匯率的幣別。

5看結果

儀表板跨車型、情境、車系並排比較；目標反推回答「要做到多少」；瀑布圖說明差在哪；GATE 報告整理成審議用的投影片。

損益儀表板

  1. 到 比較欄位 加入要比的 車型 × 情境 × 車系（或加權平均），拖曳 ⠿ 調整順序，點 ★ 設成比較基準。
  2. 切到 損益表，第二小欄選「與基準的差異」就看到每一欄跟基準差多少。
  3. 金額單位（元／千元／萬元）全系統共用；金額基礎可以切單台、年度總額、LC 總額。

某一欄算不出來（例如那個車系在這個情境還沒有銷售構成）時只略過那一欄，上方說明原因，按「從比較欄位移除」一鍵拿掉。「匯出 CSV」下載 .csv 或複製到剪貼簿；「匯出 Excel 驗算檔」見第 6 章。

目標反推與敏感度

只在畫面上試算，不會改到存檔的數字。算出結果後可以「另存成新情境…」。

瀑布圖工具

  • 兩個欄位的差異：營業淨利（或任一段小計）差在哪些科目；年度與 LC 總額可以拆出「銷量影響」。
  • 原因拆解：選起點、終點情境與科目，中間每一根是自己填的原因，對不起來的部分自動變成「其他」。原因跟 GATE 報告的「目標成本作法」是同一份清單。
  • 差異只佔整根一小段時縱軸自動放大，圖上註明「縱軸未從 0 開始」。

GATE 報告

選「目標／本回」「現況」「前回（選填）」，產生一張一頁的 16:9 投影片。「列印 / 存成 PDF」時選「另存為 PDF」；每張右上角「複製表格」直接貼進 PowerPoint 或 Excel。

6Excel 驗算檔

把一個情境的輸入數字與「科目與公式」頁建好的公式原樣搬進 Excel。損益表每一格都是真的 Excel 公式，打開就由 Excel 自己重算，再逐格跟系統的數字比對。最重要的用途是改了公式或科目之後，確認計算沒有出問題：除了驗算，檔案裡還有四項不依賴目前公式的檢查。

匯出

  1. 改公式、科目之前：到「車型與情境」或 GATE 報告按 存成快照（例：「改公式前」）。
  2. 改「科目與公式」頁的公式、科目，存檔。
  3. 儀表板工具列按 匯出 Excel 驗算檔（或工具列「匯出 ▾ → Excel 驗算檔（目前情境）」），在對話框選情境，「跟快照比」選第 1 步存的快照。
  4. 瀏覽器下載 驗算_車型_GATE_情境.xlsx，用 Excel 打開，先看「說明」頁。

六張工作表

以下是示範資料目標情境的實際畫面（用 LibreOffice 打開）。為了示範檢查的效果，匯出前先存了快照，再刻意改了三個地方：生產毛利的公式寫錯（多加回一般材料）、季Margin 改成固定 1%、新增一個沒有掛在任何小計底下的「新增的認證費」。顏色的意思：藍字黃底 = 輸入值，黑字 = 公式，綠字 = 引用其他工作表，灰底 = 系統數字（匯出當下的固定值）。

怎麼驗算

  1. 打開檔案時 Excel 會重算全部公式（檔案設定成開啟時完整重算）。先看「說明」頁的驗算結果：全部一致 = 系統的計算跟 Excel 用同一套公式算出來一樣。
  2. 想知道某個科目怎麼算：到「公式區」找那一列，左邊是系統公式，右邊是 Excel 公式；也可以點「損益試算」那一格，在 Excel 的公式列直接看。
  3. 想追一個數字的來源：在「損益試算」選那一格，用 Excel 的「追蹤前導參照」，會一路指到「輸入」與「開發總投」的格子。
  4. 想試算：改「輸入」或「開發總投」的藍字，損益試算跟著重算；「驗算」頁會顯示跟匯出當時的差異，那是改動的影響，不是錯誤。
每次改版都驗過：開發時用 node tools/verify-excel.js 把檔案裡的快取值全部拿掉，交給 LibreOffice 從頭重算，逐格對系統數字（含車系個別公式、REF 跨車型、外幣成本、只攤給部分車系的外幣投資、低減目標、攤提基準台數、IF／比較／除法等自訂公式），也確認故意改壞的科目表會被下一節的檢查抓到。

改公式之後的檢查

「驗算」一致只代表系統照現在的公式算對了。公式本身改壞時（小計少算一段、科目沒掛進小計、同一筆成本扣兩次），Excel 用同一個公式重算也會一致。下面四項檢查不看現在的公式怎麼寫，專門抓這類問題。

檢查怎麼做抓得到
結構檢查用系統預設的算法在 Excel 另外算一次各段小計：A = P8 + P9、B = Σ子科目、C = A − B、E = C − Σ子科目…，以及 營業淨利 = 收入 − 全部成本費用明細小計公式改壞、少算或多算一段
科目影響系統把每個明細科目逐一 +1,000 元重算，營業淨利的變化 ÷ 1,000沒有算進營業淨利（0）、重複計算（−2）、掛錯段落（正負號相反）
跟系統預設比較每個科目的公式、計算來源、所屬小計跟系統預設（原 Gate F 試算表的算法）比哪些科目被改過、哪些是新增的，審核時只看這幾條
變動檢查選了快照才有：每個科目 快照 → 現在 的差異，加上公式有沒有改「公式沒改、數字卻變了」的科目：上游被改到，或輸入有改
標紅、標黃不一定是錯。刻意改的算法（例如季Margin 改成固定 1%）也會被標出來；逐條確認「這是不是我要的改動」。

發現錯誤怎麼辦

哪裡標紅代表什麼怎麼處理
「驗算」不一致（沒改過輸入）系統計算的問題，使用者改不了把驗算檔和「匯出 ▾ → 匯出情境」的資料包交給系統維護人員；驗算檔已經標出是哪個科目、哪個車系、差多少
結構檢查、科目影響、跟預設比較、變動檢查科目表的設定（公式、所屬小計）有問題看旁邊的「怎麼修正」：到「科目與公式」改；或直接在驗算檔裡改好，用「從 Excel 匯入」寫回

「怎麼修正」會寫到科目：科目影響列出是哪些科目重複算到它（例：「材料成本-LP 被『銷貨成本合計』『重複的材料』都算到，留一個就好」），變動檢查列出它上游哪些科目變了、哪個的公式改過，公式區寫出系統預設的算法。科目表通常有人負責維護：可以自己改了再「匯出車型」交回去，或把驗算檔交給負責的人，上面已經寫好哪裡錯、要怎麼改。

從 Excel 匯入

在驗算檔裡直接修正：「損益試算」改公式，「輸入」「開發總投」改藍字（售價、銷量、參數、匯率、成本金額、投資金額、低減目標），存檔後匯入回系統。

  1. 在 Excel 改好、存檔（檔案格式維持 .xlsx）。
  2. 系統裡按 從 Excel 匯入…（儀表板工具列、「科目與公式」頁右上 ⋯，或工具列「更多… → 從 Excel 驗算檔匯入…」），選這個檔案。
  3. 預覽列出「公式」「輸入數字」的 現在 → 匯入後，以及「無法匯入」的格子與原因。勾選要匯入的項目，按 匯入勾選的項目。
  4. 匯入前系統自動存一份快照「匯入 Excel 前」。匯入後再匯出一次驗算檔、選這個快照，確認四項檢查都通過。
  • 只匯入改過的格子：跟匯出當時一樣的格子不會動；匯出之後系統裡同一個地方也改過時，標「匯出後系統也改過」，預設不勾。
  • 只改了部分車系：存成那幾個車系的個別公式。
  • 無法匯入：用了系統沒有的函式（只能用 SUM、ROUND、ROUNDUP、ROUNDDOWN、MIN、MAX、ABS、IF）、引用別的車系欄或三張表以外的格子、改了加權平均欄或跨情境引用的數字。
  • 不能在 Excel 新增科目：先在系統新增科目，再匯出、改公式、匯入。存檔時一樣會檢查循環引用、找不到的科目，擋下來的項目會列出原因。

常見問題

  • 開發總投攤提是 0？銷售構成只填了構成比，沒填月台數或 LC 年限，LC 總台數是 0。補上，或在開發總投頁填「攤提基準台數」。
  • 參數旁標「未填 = 0」？這個情境沒填，也沒有預設值。到「參數與匯率」補上，或編輯參數設預設值。
  • 同事給的資料包要怎麼加進來？工具列「匯入資料包…」選「合併匯入」：資料包裡有的車型（或情境）以資料包為準，其他不動。合併前建議先「匯出全部」備份。
  • 另一個分頁說資料已經被修改？同一份資料在兩個分頁同時開啟時，後開的那一頁會暫停存檔，按「重新整理」就好。
  • Excel 驗算檔有科目不一致？如果沒有改過輸入，請把檔案與資料包一起交給維護的人；公式區的「對照說明」會寫出那個科目的翻譯方式。
  • 改了公式，怎麼確定沒改壞？改之前存快照，改完匯出驗算檔並選那個快照，看「說明」頁的四項檢查（見第 6 章「改公式之後的檢查」）。
  • 驗算檔發現公式有錯，但我不負責維護科目表？驗算檔上「怎麼修正」已經寫好哪裡錯、要怎麼改，交給負責的人；或在驗算檔裡改好，交給他用「從 Excel 匯入」（見第 6 章「發現錯誤怎麼辦」）。
